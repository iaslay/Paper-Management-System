## 实现选择

1. **本机 SQLite**：当前环境未安装 Docker。通过 SQLAlchemy 保留 PostgreSQL 连接能力，以 SQLite 交付可直接运行的个人版本；本阶段没有进行 PostgreSQL 实机验收。
2. **轻量文件准备**：上传时在隔离子进程检查文件与页数，20 秒超时后结束检查；请求返回已经准备完成的论文记录。暂不引入 Redis 与 Celery，后续 AI 生成时再接入持久任务队列。
3. **统一分类基础表**：研究方向、主题和普通标签共用表，通过类型与接口字段隔离；研究方向保留多对多关系、名称注册和合并映射，减少重复维护逻辑。
4. **按需加载阅读器**：论文库初始脚本约 286 KB，打开原文才加载约 440 KB 的阅读模块和独立 worker，避免所有页面都加载阅读依赖。
5. **数据目录隔离**：正式空间默认 `data`，浏览器验收空间为 `.test-data/browser`；验收时上传的文件已保留，不自动迁移到正式库。

当前没有 OCR 服务、模型调用、公开注册或在线发布。研究方向的人工管理已完成；AI 推荐与简介卡片会在生成模块阶段一起实现。

## 自动验证

最终结果：**22 项后端验证通过；前端 TypeScript 检查与生产构建通过。**

覆盖：

- 初始化、登录、退出、密码摘要与私有文件访问；去空白后的用户名长度仍需满足规范。
- 非法来源和缺少写请求校验头拒绝；登录失败限流。
- PDF 中文元数据、分段读取、空／损坏／加密／伪装文件、大小／页数／容量限制。
- 并发同文件只保留一条记录，存储计数不重复。
- 分类名称与别名的全半角／大小写归一、类型校验和冲突处理。
- 任一／全部研究方向、未分类、方向别名、去重分页与计数。
- 中文和英文作者检索，作者修改后检索内容同步更新。
- 编辑版本冲突、阅读完成时间与收藏状态。
- 分类合并与论文关联去重，归档／恢复，回收站文件重复提示。
- 批量逐项结果与方向上限、跨空间记录隔离、静态路径越界拒绝。

测试使用独立目录，未向正式空间建立预设账号。测试框架对旧 httpx 适配层给出一条弃用提示，当前测试执行正常；后续升级测试依赖时可切换推荐的适配层。

## 当前限制与下一阶段

- 已读状态可以保存；AI 简介卡片、推荐方向和云端模型配置尚未接入。
- 原文为基础预览，尚无阅读位置持久化、文字选区、高亮和个人笔记。
- 暂无完整备份恢复界面；手动备份需停止服务后复制整个数据目录。
- 尚未用 1,000 篇论文进行性能验收，也未完成完整的多栏／公式／表格论文评测。
- 服务当前针对本机单用户运行；对外访问、多人协作及多个 API 进程需另外进行部署和并发事务验证。
