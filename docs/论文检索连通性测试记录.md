## 结论

arXiv 公开 API 已实际检索成功；电子科大校园 VPN 登录后的 IEEE 网页关键词检索也已通过，页面识别到学校机构，并返回论文结果。未配置密钥的 IEEE 元数据 API 请求仍只有此前的拒绝记录，不能把网页机构权限视为 API 授权。当前看板尚无联网发现页面和接口，本次测试直接访问外部来源。

## 复测

仓库提供只读诊断脚本 `backend/scripts/check_literature_sources.py`：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.venv/Scripts/python.exe backend/scripts/check_literature_sources.py
```

脚本各请求一次，不自动重试、不读取环境中的 IEEE 密钥，也不尝试机构认证。它输出各来源的实际响应，HTTP 403 不计为检索通过。arXiv 连续调用需遵循来源限流；本轮只有一次 arXiv 检索。[arXiv API 使用限制](https://info.arxiv.org/help/api/tou.html)
