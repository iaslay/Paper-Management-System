# 论文检索连通性测试记录

2026-10-15｜基于应用 0.4.2｜范围：外部检索源测试，非 F11 功能发布

## 结论

arXiv 公开 API 已实际检索成功；未配置密钥的 IEEE API 请求被拒绝。电子科大的 IEEE 机构通道尚未完成登录后验证，不能认定已检索成功或学校没有订阅。当前看板尚无联网发现页面和接口，本轮测试直接访问外部来源。

| 对象 | 实际操作与返回 | 判断 |
| --- | --- | --- |
| arXiv 公开检索 | HTTPS 请求 `search_query=all:memory AND cat:cs.CL`，`start=0`、`max_results=3`；HTTP 200、Atom 数据，约 1.31 秒；来源报告 6,605 条并返回 3 条论文 | 该次关键词检索通过 |
| IEEE 元数据 API | 无密钥请求 `querytext=long term memory`、`max_records=3`；HTTP 403，正文 `<h1>Developer Inactive</h1>`，约 2.94 秒 | 该次请求未取得检索结果；不能仅凭此响应判定学校订阅情况 |
| IEEE 网页 | 浏览器页签显示 `IEEE Xplore`，跳转至 `/Xplore/home.jsp`；读取页面和截图超时，未完成关键词提交 | 网页检索尚未验证 |
| 电子科大校园 VPN | 公开网页可读取到校园 VPN FAQ；浏览器页签显示校园 VPN 系统，但交互和截图连续超时，未取得登录后的资源列表 | 机构登录、IEEE 资源入口和订阅覆盖尚待验证 |

## 后续验证条件

1. 用户在[电子科大校园 VPN](https://vpn.uestc.edu.cn/)完成登录，从资源列表进入 IEEE，确认当前浏览器确实具有机构访问上下文。学校 FAQ 说明，另在地址栏输入应用 URL 不会自动进入网页版代理。
2. 页面交互恢复后，实际输入一个关键词，记录结果题名、DOI／文章号及来源，不能把首页打开当作检索成功。
3. 选择一篇机构可访问的原文核对获取情况；若只测站内 IEEE API，则使用另行获批的 API 密钥重测。IEEE 官方要求每次 API 请求携带密钥。[官方接入步骤](https://developer.ieee.org/Quick_Start_Guide)

浏览器控制超时不是学校权限错误或 IEEE 无结果的证据；不通过更换账户、复制 Cookie 或绕过登录来推断成功。

## 复测

仓库提供只读诊断脚本 `backend/scripts/check_literature_sources.py`：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.venv/Scripts/python.exe backend/scripts/check_literature_sources.py
```

脚本各请求一次，不自动重试、不读取环境中的 IEEE 密钥，也不尝试机构认证。它输出各来源的实际响应，HTTP 403 不计为检索通过。arXiv 连续调用需遵循来源限流；本轮只有一次 arXiv 检索。[arXiv API 使用限制](https://info.arxiv.org/help/api/tou.html)
